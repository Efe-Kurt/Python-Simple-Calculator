# Simple Python Calculator

A simple, command-line basic calculator built with Python.

## Features

- Basic arithmetic operations: Addition, Subtraction, Multiplication, Division
- Zero division error handling (`ZeroDivisionError`)
- Clean and minimal CLI interface

## Getting Started

Clone the repository to your local machine:

```bash
git clone https://github.com/Efe-Kurt/Python-Simple-Calculator.git
cd Python-Simple-Calculator
```

Run the application:

```bash
python calculator.py
```
